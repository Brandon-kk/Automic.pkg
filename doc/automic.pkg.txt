2. Installation					*automic.pkg-install*

Execute once inside Neovim: ~

>
	local dest = vim.fs.joinpath(
	  vim.fn.stdpath("data"), "site", "pack", "core", "opt", "Automic.pkg")
	vim.fn.mkdir(vim.fs.dirname(dest), "p")
	if vim.fn.isdirectory(dest) == 0 then
	  vim.fn.system({
	    "git", "clone", "https://github.com/Brandon-kk/Automic.pkg", dest,
	  })
	end
<

In |init.lua|: ~

>
	vim.cmd.packadd("Automic.pkg")
<

Do not call |Pack.register()| for Automic.pkg.

3. Boot							*Pack.boot()*
							*Pack*

After |:packadd|, the global |Pack| table is available.

>
	Pack.boot("packages.configs")
	  :options("core.options")
	  :keys("core.keymaps", " ")
	  :commands("core.commands")
	  :lsp("core.lsp")
	  :autosave()
	  :run()
<

	Call					Purpose ~
	Pack.boot({module?})		Load all declaration modules under
					the given directory. The directory
					must lie under
					|stdpath|("config")/lua.
					`Pack.boot("packages.configs")`
					loads `lua/packages/configs/*.lua`
					in alphabetical order.
	:options({values})		Apply global settings. See
					|Pack.boot.options()|.
	:keys({entries}[, {mapleader}])
					Define keymaps. Optional second
					argument sets |vim.g.mapleader|.
					See |Pack.boot.keys()|.
	:commands({groups})		Define autocmd groups. See
					|Pack.boot.commands()|.
	:lsp(...)			Associate filetypes with language
					servers. See |Pack.boot.lsp()|.
	:autosave({opts?})		Enable autosave. See
					|Pack.boot.autosave()|.
	:run()				Complete the boot sequence
					(required once per session).

Arguments may be module names that return a table, or tables supplied
inline.

						*Pack.boot.options()*
:options({values})

	Global settings only. Window- and buffer-local tables (`wo` / `bo`)
	are not accepted.

	Field		Purpose ~
	g		|vim.g| assignments
	opt		|vim.opt| defaults
	hl		Highlight definitions (|nvim_set_hl()|; a string
			value means `{ link = ... }`; re-applied on
			|ColorScheme|)
	diagnostic	|vim.diagnostic.config()|
	plugins		Function (or map of functions) for third-party
			global configuration (e.g. |vim.g|, |vim.filetype|)

	Application order: g → opt → diagnostic → hl → plugins.

>
	:options({
	  g = { mapleader = " " },
	  opt = { number = true },
	  plugins = function()
	    vim.g.my_plugin = { a = "xxx" }
	  end,
	})
<

						*Pack.boot.keys()*
:keys({entries}, {mapleader?})

	Each entry has the form `{ mode, lhs, rhs, opts? }`
	(|vim.keymap.set()|).

	Optional {mapleader} sets |vim.g.mapleader| before mappings are
	created.

	When {opts}.event is set, the mapping is attached for matching
	buffers when that event occurs (including buffers that already
	match, where applicable).

						*Pack.boot.commands()*
:commands({groups})

	Keys are |augroup| names. Values are a single autocmd definition
	or a list. Each definition requires `event`; remaining keys are
	passed to |nvim_create_autocmd()|.

						*Pack.boot.lsp()*
:lsp({enable}, {disable?})

	Accepted forms: ~
		:lsp("module")
		:lsp({ filetype = server, … })
		:lsp({ enable = …, disable = … })
		:lsp(enable, disable)

						*Pack.boot.autosave()*
:autosave({opts?})

	Enables autosave. Writes on |InsertLeave| and, after a short
	debounce, on |TextChanged|. Skips readonly buffers, non-empty
	'buftype', unmodified buffers, and unnamed buffers.

	Field		Purpose ~
	ft		Filetypes to exclude
	buftype		Buftypes to exclude
	filename	|glob2regpat| patterns to exclude
	enable		When false, disables autosave

						*Pack.boot.run()*
:run()

	Required once per session. Loads declarations and performs
	package install/sync.

4. Registration						*Pack.register()*

>
	Pack.register({
	  "https://github.com/user/plugin.nvim",
	  module = "plugin",
	}):load({
	  config = function(plugin)
	    plugin.setup({})
	  end,
	})
<

Returns a handle providing |Pack.load()| / |Pack.lazy()|, or |nil| on
validation failure. `Pack.register({})` is a no-op.

							*Pack.Plugin*
	Field		Purpose ~
	[1]		Repository URL (mutually exclusive with `spec`)
	spec.src	Repository URL
	spec.name	Installation directory name
	spec.version	Branch, tag, commit, or |vim.version.range()|
	module		Lua module for `config` / |require()| (required)
	path		Local package root; skips remote installation
	dev		When true, resolve root as
			|g:automic_dev_path| / <name>
	dependencies	Dependent packages
	cond		When false (or a function returning false), skip
			installation and load
	build		Executed after install/update: Ex command
			(e.g. `:TSUpdate`), argv list
			(`{ "cmd", "arg" }`), or function
	lock		When true, exclude from |:PackUpdate|
			(default true for `path` / `dev`)

	`utils` and `var` belong on |Pack.load()| or |Pack.lazy()|.

Local package: ~

>
	Pack.register({
	  path = vim.fn.expand("~/code/my-plugin.nvim"),
	  module = "my-plugin",
	}):load({ config = function(p) p.setup({}) end })
<

Development root: ~

>
	vim.g.automic_dev_path = vim.fn.expand("~/code")
	Pack.register({
	  dev = true,
	  spec = { name = "my-plugin.nvim" },
	  module = "my-plugin",
	}):lazy({ config = function(p) p.setup({}) end })
<

							*Pack.lock*
							*g:automic_dev_path*
	`lock = true`		Exclude this dependency tree from
				|:PackUpdate|.
	nvim-pack-lock.json	Remote revision pins owned by |vim.pack|.
	g:automic_dev_path	Root directory for `dev = true`.

							*Pack.Dep*
Dependency entry (URL string or table): same fields as |Pack.Plugin|, with
optional `config` / `utils` / `build` scoped to that dependency.

5. Load policy						*Pack.load()*

handle:load({opts?})

	With no trigger, load immediately. Otherwise specify exactly one
	of `event`, `keys`, `cmd`, `ft`, or `colorscheme`.

	At most one successful |Pack.load()| or |Pack.lazy()| is permitted
	per package per session.

							*Pack.LoadOpts*
	Field		Purpose ~
	event		Load on the given autocmd (`"Lazy"` is invalid;
			use |Pack.lazy()|). May include `once` / `pattern`
			/ `group` / …
	keys		Load on the given key (shared among packages that
			claim the same key)
	cmd		Load on the given user command (shared)
	ft		Load for the given |FileType| patterns
	colorscheme	Load on |:colorscheme|; `true` uses the package
			name
	defer		Only with `event = "UIEnter"`: defer load by one
			|vim.schedule| turn
	config		Invoke `plugin.setup(...)`, or pass a table to
			`setup`. May read `var`. Plugin |vim.g| settings
			belong in |Pack.boot.options()|.
	utils		Additional modules for `var` functions only
	var		Environment for `config`. Entry
			`{ use = true, callback = fun(plugin) }` runs
			once after successful setup.


==============================================================================
6. Lazy load						*Pack.lazy()*

handle:lazy({opts?})

	Load once after the UI is ready. Accepted fields: `config`,
	`utils`, `var` only. For event, key, command, filetype, or
	colorscheme triggers, use |Pack.load()|.

							*Pack.LazyOpts*
	config		fun(plugin)|table
	utils		table
	var		table

7. Commands					*automic.pkg-commands*

						*:PackUpdate*
:PackUpdate[!] [name ...]
	Update packages. With `!`, skip confirmation. Trees with
	`lock = true` are excluded. The session may restart afterward.

						*:PackStatus*
:PackStatus [name ...]
	Report available updates without downloading.

						*:PackReBuild*
:PackReBuild[!] [name ...]
	Re-run registered `build` steps. With `!`, force. On success the
	session may restart.

						*:PackLoadProfile*
:PackLoadProfile
	Display load timing.

						*:PackHealth*
:PackHealth [name ...]
	Open the health report. Press `q` to close.

						*:PackClean*
:PackClean[!]
	Remove packages absent from the current declarations. The session
	may restart afterward.

8. Helpers					*automic.pkg-helpers*

							*Pack.root()*
Pack.root({markers})
	Return a project-root callback for LSP `root_dir`. `.git` is always
	included among markers.

							*Pack.path()*
Pack.path({name})
	Return the on-disk path of a package, or nil.

							*Pack.available()*
Pack.available({name})
	Return whether a package is installed.

							*Pack.parse()*
Pack.parse({spec})
	Return the installation directory name for a URL or specification.
